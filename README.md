# Creative Bus — реклама на транспорте в Таганроге

Статический сайт, без билда: чистый HTML / CSS / JS.
Заказчик — ИП Хазанов Михаил Сергеевич (бренд Creative Bus, юр. лицо AGV Trans).

Макет: [Figma → Creative bus site](https://www.figma.com/design/o1syNp93H3v2dyA3JHp4em/Mary?node-id=5725-10350)

## Запуск локально

```bash
cd ~/projects/agvtrans-landing
python3 -m http.server 8013
# http://localhost:8013
```

## Структура

```
*.html                 14 страниц — в корне, этого требует GitHub Pages
├─ index.html          главная
├─ about.html          о компании
├─ services.html       все услуги
├─ service-*.html      4 услуги: наклейки, бортовая, спинки, листовки
├─ pricing.html        прайс
├─ pricing-print.html  версия прайса под печать в PDF
├─ cases.html          кейсы
├─ contacts.html       контакты + форма
├─ privacy.html        политика обработки ПД (ст. 18.1 152-ФЗ)
├─ consent.html        согласие на обработку ПД
└─ requisites.html     реквизиты

css/styles.css         все стили. Брейкпоинты: 640 / 641–1024 (планшет) / 1280
js/script.js           карусели, аккордеоны, меню, маска телефона, форма
assets/img/            фотографии и кейсы (WebP, ≤1920px, q82)
assets/icons/          иконки и логотипы
assets/docs/           pricing.pdf
backend/               приёмники заявок, пока не подключены (см. ниже)
robots.txt sitemap.xml site.webmanifest favicon.ico
```

Один CSS и один JS на весь сайт — так браузер скачивает их один раз
и дальше берёт из кеша на всех страницах. Разбивать по страницам смысла нет:
файлы маленькие, а запросов стало бы в 14 раз больше.

## SEO

- уникальные `title` / `description` / `canonical` на каждой странице
- Open Graph + Twitter Card, картинка `assets/img/og-cover.jpg`
- JSON-LD `LocalBusiness` с реквизитами, адресом и телефоном
- `sitemap.xml` со всеми 14 страницами, `robots.txt`
- favicon во всех размерах + `site.webmanifest`
- SEO-текст с ключами внизу каждой страницы услуги

## Форма заявки

Фронт готов целиком: маска телефона, валидация, галочка согласия
(**не** проставлена заранее — иначе согласие недействительно по 152-ФЗ),
скрытое поле-ловушка от ботов, состояние загрузки, экраны «спасибо» и ошибки.

Приёмник пока не подключён: `FORM_ENDPOINT = ''` в `js/script.js`.
Пока так — форма не показывает фальшивое «спасибо», а выдаёт телефон и почту.

### Как включить письма

Нужен хостинг с PHP (reg.ru, timeweb, beget — 150–300 ₽/мес, обычно берётся
вместе с доменом). Там:

1. залить сайт целиком, включая `backend/form.php`
2. в `backend/form.php` проверить `$MAIL_TO`, `$MAIL_FROM` и `$ALLOW_ORIGIN`
3. в панели хостинга создать ящик `site@<домен>` — с него уходят письма
4. в `js/script.js` написать `const FORM_ENDPOINT = '/backend/form.php';`

Письмо приходит таблицей: имя, телефон, почта, сообщение, страница, время
по Москве и отметка о согласии. `Reply-To` подставляется на почту клиента —
можно отвечать прямо из ящика.

`backend/index.js` — тот же обработчик для Яндекс.Облака (Cloud Function
на nodemailer), если когда-нибудь захочется без хостинга. Не развёрнут.

Данные в обоих вариантах остаются в России — это записано в политике
(«трансграничная передача не осуществляется»), поэтому зарубежные сервисы
вроде Formspree или Google Forms не подходят.
